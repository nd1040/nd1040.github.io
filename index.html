Deploying on GitHub Pages (Step-by-Step):

  1. Create a new public repository on GitHub named yourusername.github.io
  2. Upload this exact file and name it index.html in the main branch root folder.
  3. Go to **Settings** → **Pages** in your GitHub repository.
  4. Under **Build and deployment**, select **Source** as Deploy from a branch and set branch to main / (root).
  5. Click **Save**. Your site will be live at https://yourusername.github.io within minutes!
